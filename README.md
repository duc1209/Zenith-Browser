# Zenith Browser ⚡

**Zenith Browser** là trình duyệt desktop thế hệ mới: **Siêu nhẹ, tối ưu RAM**, loại bỏ mọi chi tiết thừa thãi, sở hữu giao diện kính mờ (Glassmorphism) Deep Dark tuyệt đẹp và tích hợp sẵn đầy đủ các công cụ mạnh mẽ.

![Zenith Logo](assets/zenith.png)

## 🌟 Điểm Nổi Bật

- ⚡ **Siêu Nhẹ & Tối Ưu RAM Cực Đỉnh**: Giới hạn V8 Heap Memory 512MB, cơ chế Sleep Tabs và giải phóng RAM ngầm giúp máy luôn mượt mà kể cả khi mở nhiều tab.
- 🖼️ **Giao Diện Tràn Viền Tuyệt Đẹp**: Loại bỏ hoàn toàn thanh bên gây chật chội; tab dạng viên nang nổi (Floating Pill Tabs), thanh Omnibox kính mờ với viền phát sáng Emerald sang trọng.
- 🛡️ **Zenith Shield (Chặn Quảng Cáo Mạnh Mẽ)**: Tích hợp bộ lọc quốc tế + Việt Nam (ABPVN), tự động bỏ qua video quảng cáo YouTube và ẩn khung quảng cáo trống.
- 🎬 **Zenith Media Grabber (Bắt Link Tải Video)**: Tự động phát hiện và bắt link tải video/audio (`.mp4`, `.webm`, `.m3u8`, `.mp3`...) chất lượng cao.
- 📌 **Ghim Video (Picture-in-Picture)**: Tách video xem dạng cửa sổ nổi thu nhỏ trên mọi ứng dụng.
- 🌙 **Smart Dark Mode**: Thuật toán bảo vệ mắt thông minh, không làm biến màu hình ảnh và video.

## 🚀 Khởi Chạy

```bash
npm start
```
